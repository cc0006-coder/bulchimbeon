## English

### Highlights

- **Linux daemon v0.1.** Bulchimbeon now runs on Linux as a small Go daemon with a command line:
  `bulchimbeon run | status | doctor | config`. It holds two logind inhibitors (sleep and idle) while an
  agent is working, and runs as a systemd user unit. It uses the same engine as the macOS app: the Go port
  must pass the same golden fixtures (`testdata/engine`) as the Swift core, in CI on every pull request.
  Tested on Ubuntu 24.04. Tarballs and `.deb` packages for amd64 and arm64 are attached below. (#16)
- **Uniform themes.** Pick the soldier's uniform from the **🎽 Uniform** menu: the default combat
  uniform, Navy or Arctic. Only the uniform's colors and pattern change; the default looks exactly as
  before. New settings key `uniformTheme`. (#17)
- **Contributor docs.** English-first README (Korean in `README.ko.md`), a full bilingual CONTRIBUTING
  guide, new issue forms (feature request, translation fix), a PR template, and a documented 1.0
  compatibility promise for settings keys, launch flags and the duty-log format (`docs/compatibility.md`).
  (#7, #8)
- **Safety rails.** Least-privilege workflows with SHA-pinned Actions, approval before fork PRs run CI,
  protected `main` branch and `v*` tags, `AGENTS.md`, `CODEOWNERS` and an AI-assisted contribution
  policy. (#15)

### Install

- **macOS:** `brew update && brew upgrade --cask bulchimbeon`, or
  `brew install --cask s3onghyun/tap/bulchimbeon` for a new install. Or download `Bulchimbeon-0.7.0.zip`
  below.
- **Linux (Homebrew):** `brew install s3onghyun/tap/bulchimbeon-linux`, then
  `brew services start bulchimbeon-linux`.
- **Linux (tarball or .deb):** see [Linux → Install](https://github.com/s3onghyun/bulchimbeon#install-1).
  Pick one method only, so that only one daemon runs.

Verify any file: `sha256sum -c SHA256SUMS --ignore-missing` (Linux) or
`shasum -a 256 -c Bulchimbeon-0.7.0.zip.sha256` (macOS), and
`gh attestation verify <file> --repo s3onghyun/bulchimbeon`.
